# Contributing to Plaintext Maven Repository

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## How to Contribute

### Reporting Bugs

- Use [GitHub Issues](https://github.com/daniel-marthaler/plaintext-mvn/issues) to report bugs
- Include steps to reproduce, expected behavior, and actual behavior

### Pull Requests

1. Fork the repository
2. Create a feature branch from `master`: `git checkout -b feature/my-feature`
3. Make your changes
4. Commit with a descriptive message
5. Push to your fork and open a Pull Request
